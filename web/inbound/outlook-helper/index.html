Outlook helperបើកអ៊ីមែល Outlook ពីកម្មវិធី ទទួលទំនិញ · Open Outlook drafts from Inbound

ដំឡើងតែម្តងលើកុំព្យូទ័រនីមួយៗ។ បន្ទាប់មក ប៊ូតុង 📧 បើកក្នុង Outlook នឹងបើកសេចក្តីព្រាងអ៊ីមែល Outlook ភ្លាមៗ ជាមួយ PDF ភ្ជាប់រួច ដូចម៉ាក្រូ Excel។ Install once on each computer. After that, 📧 Open in Outlook opens the Outlook draft straight away with the PDF attached, like an Excel macro.

⬇ ទាញយក · Download (iSteel-Outlook-helper.zip)
1

ចុចលើ zip ដែលទាញយក រួចចុចពីរដងលើ iSteel Outlook helper.vbs

Open the downloaded zip and double-click iSteel Outlook helper.vbs. No admin rights needed.
2

ចុច OK · កម្មវិធី ទទួលទំនិញ បើកឡើងវិញដោយខ្លួនឯង

Click OK. The Inbound app opens again by itself and now knows this computer has the helper.
3

ពេលចុច បើកក្នុង Outlook លើកដំបូង Chrome សួរ៖ ធីក Always allow រួចចុច Open

The first time you click Open in Outlook, Chrome asks to open the helper: tick Always allow, then click Open.
ត្រូវការ Outlook (classic) លើកុំព្យូទ័រ។ ដើម្បីលុប៖ ចុចពីរដងលើ %LOCALAPPDATA%\iSteel\Outlook\iSteel Outlook helper.vbs។ Needs the classic Outlook desktop app. To remove it, double-click %LOCALAPPDATA%\iSteel\Outlook\iSteel Outlook helper.vbs and click Yes. If Windows warns about the file, click More info, then Run anyway.
